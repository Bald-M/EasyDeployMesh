# PE 品牌 Logo 与镜像名称识别调研

更新日期：2026-08-24

## 结论

EasyDeployMesh 可以用**文件名的品牌前缀**为第三方 PE 选择展示标识，但只能把它作为 UI 提示，不能把它当作镜像真实性或安全性的证明。最稳妥的实现是：规范化文件名（小写、去扩展名、把空格与 `-` 视为分隔符），按下表从上到下匹配；无法可靠匹配时显示项目自己的通用 PE 图标。不要仅凭 `PE`、`WinPE`、版本号或 ISO 内的 Windows 文件判断品牌。

Logo 方面，各项目官网或官方代码仓库能证明品牌名称及其当前视觉呈现，但**没有找到任何一个项目明确授予 EasyDeployMesh 再分发其 Logo 的许可**。开源代码许可证也不当然覆盖商标或 Logo。因此生产实现应先取得各权利人的书面许可；在此之前，建议用中性的文字徽标/首字母头像，并明确标注“第三方 PE、非官方合作”。官网 favicon 可作为设计核对样本，不应直接热链，也不应在没有许可时复制进仓库。

### 推荐匹配顺序与约束

1. 只检查 basename，不检查完整路径，避免用户目录名触发品牌。
2. 去掉最后一个已知镜像扩展名（至少 `.iso`），再做 Unicode 小写化。
3. 前缀后必须是结尾或分隔符 `_`、`-`、空格、`.`，避免 `wepeople.iso` 误判为 WePE。
4. 可记录版本文本用于显示，但不要因未知版本格式而拒绝品牌识别。
5. 品牌识别结果不能影响镜像完整性校验、可启动性判断或部署安全策略。
6. 若未来读取 ISO 内容，可把卷标、签名者、已知清单哈希作为额外证据；仍应保持“未知”分支并 fail closed，不以 Logo 替代真实性校验。

## Logo 获取与复用风险

### 为什么官网有图不等于可以打包

中国《著作权法》把美术作品纳入保护范围，复制、信息网络传播等权利原则上属于著作权人；法定许可/合理使用是有限例外，并不自然覆盖把第三方 Logo 打包进软件 UI 的场景。[全国人大：《中华人民共和国著作权法》](https://www.npc.gov.cn/c2/c30834/202011/t20201119_308796.html)

Logo 同时可能构成商标。国家知识产权局说明，注册商标许可通常通过许可合同完成并办理备案；现行商标法也把在互联网商业活动中用于识别来源纳入“商标的使用”，并禁止容易导致混淆的未授权使用。[国家知识产权局：什么是商标的许可使用](https://www.cnipa.gov.cn/art/2021/12/21/art_1750_172331.html) [《中华人民共和国商标法（2026 年修订）》](https://www.cnipa.gov.cn/art/2026/6/26/art_95_206942.html)

项目开源也不能直接推出 Logo 可用。例如 Edgeless 官方仓库只明确说**自编代码**采用 MPL-2.0，并强调仓库并非所有文件都是其自编代码；FirPE 页面同样谈的是源代码及修改发布条件，而不是品牌图形授权。[Edgeless 官方仓库许可说明](https://github.com/EdgelessPE/Edgeless) [FirPE 官方说明](https://firpe.cn/page-247)

### 落地建议

- 第一阶段（无需外部授权）：为六个品牌使用 EasyDeployMesh 自绘的中性圆形字母徽标（`EU`、`E`、`F`、`H`、`USM`、`WePE`），旁边显示完整产品名，并加上 tooltip：“根据文件名识别；非官方认证”。不要临摹对方独特图形、字体编排或配色到足以造成官方合作误认。
- 第二阶段（取得许可后）：向每个权利人索取 SVG/PNG 原文件、允许的尺寸/留白/底色、是否允许随安装包再分发、是否要求署名及撤回机制；把授权记录和素材来源版本一并保存。
- 无论是否获准，都应把第三方 Logo 作为本地静态资源打包，不从官网热链，以免离线失效、被跟踪或上游替换内容。
- UI 与文档明确说明 EasyDeployMesh 与这些第三方 PE 项目无隶属或背书关系；Logo 只用于指称用户所选镜像。
- 不要抓取搜索引擎图片或第三方下载站图标。优启通与微PE尤其存在大量近似域名，错误素材会同时带来归属、供应链和误导风险。

## 实现验收建议

- 表驱动单元测试覆盖六个截图文件：`EasyU_v3.6.iso`、`Edgeless_Beta_4.1.0.iso`、`FirPE-V2.1.1.iso`、`HotPE-V2.8.251018.iso`、`Usm_v5F.ISO`、`WePE64_V2.2.iso`。
- 增加大小写、空格、连字符、完整路径及错误相似前缀测试；例如 `USM-v5.iso` 命中，`museum.iso`、`edge.iso`、`wepeople.iso` 不命中。
- 未识别文件必须稳定显示通用 PE 图标，不能出现破图或远程请求。
- 在 UI 上把品牌判断措辞设为“根据文件名识别为 …”，不要写成“官方”“已验证”或“安全”。

## 资料可信度说明

除 EasyU 旧式文件名外，命名依据均来自项目官网或权利主体的官方仓库/论坛。`EasyU_v3.6.iso` 来自用户提供的实际文件列表，并与长期使用的 EasyU 名称一致，但由于原官网当前不可稳定访问，本调研不把它当作官方下载证明。所有 Logo URL 都只是官方页面当前素材的**核对入口**，不是许可证或永久资源地址。
